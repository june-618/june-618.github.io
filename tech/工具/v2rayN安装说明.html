v2rayN 安装说明

安装概况

  • 安装时间：2026-04-01
  • 安装设备：macOS 15.6
  • 处理器架构：Apple Silicon（arm64）
  • 安装软件：v2rayN
  • 安装版本：7.19.5
  • 官方仓库：https://github.com/2dust/v2rayN
  • 发布页面：https://github.com/2dust/v2rayN/releases/tag/7.19.5

本次安装记录

本次安装使用的是官方发布的 v2rayN-macos-arm64.dmg 安装包，适用于 Apple Silicon 芯片的 macOS 设备。

下载来源

本次安装文件来自 v2rayN 官方 GitHub 仓库的 Release 页面：

  • 官方仓库主页：https://github.com/2dust/v2rayN
  • 官方 Release 页面：https://github.com/2dust/v2rayN/releases
  • 本次使用的版本页面：https://github.com/2dust/v2rayN/releases/tag/7.19.5
  • 本次实际下载的安装包链接：https://github.com/2dust/v2rayN/releases/download/7.19.5/v2rayN-macos-arm64.dmg

下载与安装位置说明

本次安装过程涉及以下几个位置：

1. 下载到本机的临时目录

安装包最初下载到了下面这个临时目录中：

/tmp/v2rayN-dmg/v2rayN-macos-arm64.dmg

这是安装过程中使用的本地下载路径，不是最终应用安装路径。

2. 安装镜像挂载位置

下载完成后，系统将 dmg 挂载到了以下位置：

/Volumes/v2rayN Installer

挂载后，安装镜像中的应用包路径为：

/Volumes/v2rayN Installer/v2rayN.app

3. 最终安装位置

安装时将应用从挂载镜像复制到系统应用目录，最终安装位置如下：

/Applications/v2rayN.app

这个目录才是后续日常启动和使用的正式位置。

实际安装步骤

本次安装按以下顺序完成：

  1. 在 GitHub Release 页面确认最新正式版为 7.19.5
  2. 根据当前设备架构 Apple Silicon / arm64 选择 v2rayN-macos-arm64.dmg
  3. 将安装包下载到本地临时目录 /tmp/v2rayN-dmg/
  4. 挂载 dmg 文件，得到安装卷 /Volumes/v2rayN Installer
  5. 将 v2rayN.app 复制到 /Applications/
  6. 移除应用的隔离属性，减少 macOS 首次启动拦截
  7. 通过命令方式启动应用，确认安装成功

安装完成后，应用已放置到以下目录：

/Applications/v2rayN.app

已完成的验证：

  • 应用已成功复制到 Applications
  • 已移除隔离属性，避免首次启动被系统拦截
  • 已通过命令成功拉起应用进程

版本与安装结果确认

本次安装后，已确认以下结果：

  • 应用版本：7.19.5
  • 应用进程已成功启动
  • 可执行文件已存在于应用包内部

版本确认方式包括：

  • 读取应用自身的 Info.plist
  • 检查运行中的 v2rayN 进程

应用包目录结构入口示例：

/Applications/v2rayN.app/Contents

应用主程序路径示例：

/Applications/v2rayN.app/Contents/MacOS/v2rayN

启动方式

可通过以下任一方式启动：

  1. 在访达中打开“应用程序”，双击 v2rayN
  2. 使用 Spotlight 搜索 v2rayN
  3. 在终端执行以下命令：
open -a /Applications/v2rayN.app

首次使用说明

首次启动时，macOS 可能会提示网络权限、后台运行权限或 TUN 相关授权。这些提示属于正常现象，按系统提示允许即可。

如果要正常使用代理功能，通常还需要继续完成以下配置：

  • 导入订阅链接或手动添加节点
  • 选择要使用的核心和节点
  • 根据需要开启系统代理
  • 根据需要配置或开启 TUN 模式

说明

此次文档仅记录安装结果和基本使用入口，不包含具体订阅信息或节点配置内容。
