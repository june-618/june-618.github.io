Typora 本地数据清理脚本

概况

  • 适用系统:macOS
  • 适用软件:Typora
  • 用途:清除 Typora 在本机的登录态、会话、缓存、偏好设置、Cookie、保存的窗口状态、WebKit 存储、日志、崩溃报告以及最近文档记录,使其恢复到首次启动时的状态
  • 脚本文件:[clean-typora-macos.sh]

原理说明

Typora 在 macOS 上会把数据散落到 ~/Library/ 下若干位置,且历史版本同时用过 abnerworks.Typora、io.typora.Typora、Typora 三种 bundle id / 目录名,所以脚本对这三个前缀都做了清理。

涉及的位置:

  1. 应用数据 / 缓存 / 偏好
    • ~/Library/Application Support/{abnerworks.Typora,io.typora.Typora,Typora}
    • ~/Library/Caches/{abnerworks.Typora,io.typora.Typora,Typora}
    • ~/Library/Preferences/{abnerworks.Typora,io.typora.Typora}.plist
  2. 窗口状态 / 日志
    • ~/Library/Saved Application State/{abnerworks.Typora,io.typora.Typora}.savedState
    • ~/Library/Logs/{abnerworks.Typora,io.typora.Typora,Typora}
  3. WebKit / Cookie / 网络存储(登录态主要藏在这里)
    • ~/Library/WebKit/{abnerworks.Typora,io.typora.Typora,Typora}
    • ~/Library/HTTPStorages/{abnerworks.Typora,io.typora.Typora}{,.binarycookies}
    • ~/Library/Cookies/{abnerworks.Typora,io.typora.Typora}.binarycookies
  4. 沙盒容器 / 应用脚本
    • ~/Library/Containers/{abnerworks.Typora,io.typora.Typora}
    • ~/Library/Application Scripts/{abnerworks.Typora,io.typora.Typora}
  5. 最近打开的文档记录
    • ~/Library/Application Support/com.apple.sharedfilelist/com.apple.LSSharedFileList.ApplicationRecentDocuments/{abnerworks.Typora,io.typora.Typora}.sfl{,2,3}
  6. 崩溃 / 诊断报告
    • ~/Library/Logs/DiagnosticReports/ 下匹配 Typora*.crash / Typora*.ips / Typora*.diag 的文件

脚本流程:

  1. 解析命令行参数(--dry-run / --remove-app / -y|--yes)
  2. 拼出候选清理路径列表,过滤出真实存在的项
  3. 加入 DiagnosticReports 下匹配的崩溃 / 诊断文件
  4. 打印将要删除的清单
  5. 若 Typora 正在运行,提示退出(-y 模式下用 osascript 自动退出)
  6. 二次确认后 rm -rf 删除清单中的所有目标
  7. defaults delete 清理偏好缓存,killall cfprefsd 让 macOS 偏好守护进程重新加载
  8. 若加了 --remove-app,顺便删 /Applications/Typora.app 与 ~/Applications/Typora.app

注:脚本不会扫描或删除任何 Markdown 文档,只清 Typora 的本地状态。

使用方法

  1. 退出 Typora(脚本里也会提示退出,但提前手动退出更稳妥)

  2. 给脚本可执行权限:

    chmod +x clean-typora-macos.sh

  3. 常用调用方式:

    # 先 dry-run 看看会删哪些路径,什么都不动
./clean-typora-macos.sh --dry-run

# 交互式确认后清理本地数据(保留 Typora.app)
./clean-typora-macos.sh

# 跳过确认 + 同时移除 Typora.app
./clean-typora-macos.sh -y --remove-app

  4. 重新打开 Typora,确认登录态 / 设置 / 最近文档已重置。

注意事项

  • 强烈建议先用 --dry-run 看一遍清单,确认没有自定义主题、模板等想保留的内容会被一起删掉(这些通常落在 Application Support/abnerworks.Typora/themes 之类的子目录里)。
  • 该脚本仅适用于 macOS 路径布局,Windows / Linux 不能直接使用。
  • 用于学习与个人测试用途,正式使用请购买正版授权。

脚本源码

#!/usr/bin/env bash

set -euo pipefail

DRY_RUN=0
REMOVE_APP=0
YES=0

usage() {
  cat <<'EOF'
Clean Typora local data on macOS.

Usage:
  ./scripts/clean-typora-macos.sh [options]

Options:
  --dry-run      Show what would be removed, but do not delete anything.
  --remove-app   Also remove /Applications/Typora.app and ~/Applications/Typora.app.
  -y, --yes      Skip the interactive confirmation.
  -h, --help     Show this help.

This removes Typora login/session records, app support data, caches,
preferences, cookies, saved state, WebKit storage, logs, crash reports,
and macOS recent-document records for Typora. It does not scan for or
delete your Markdown files.
EOF
}

while [[ $# -gt 0 ]]; do
  case "$1" in
    --dry-run)
      DRY_RUN=1
      ;;
    --remove-app)
      REMOVE_APP=1
      ;;
    -y|--yes)
      YES=1
      ;;
    -h|--help)
      usage
      exit 0
      ;;
    *)
      echo "Unknown option: $1" >&2
      usage >&2
      exit 2
      ;;
  esac
  shift
done

HOME_DIR="${HOME:?HOME is not set}"
LIBRARY_DIR="$HOME_DIR/Library"

targets=(
  "$LIBRARY_DIR/Application Support/abnerworks.Typora"
  "$LIBRARY_DIR/Application Support/io.typora.Typora"
  "$LIBRARY_DIR/Application Support/Typora"
  "$LIBRARY_DIR/Caches/abnerworks.Typora"
  "$LIBRARY_DIR/Caches/io.typora.Typora"
  "$LIBRARY_DIR/Caches/Typora"
  "$LIBRARY_DIR/Preferences/abnerworks.Typora.plist"
  "$LIBRARY_DIR/Preferences/io.typora.Typora.plist"
  "$LIBRARY_DIR/Saved Application State/abnerworks.Typora.savedState"
  "$LIBRARY_DIR/Saved Application State/io.typora.Typora.savedState"
  "$LIBRARY_DIR/Logs/abnerworks.Typora"
  "$LIBRARY_DIR/Logs/io.typora.Typora"
  "$LIBRARY_DIR/Logs/Typora"
  "$LIBRARY_DIR/WebKit/abnerworks.Typora"
  "$LIBRARY_DIR/WebKit/io.typora.Typora"
  "$LIBRARY_DIR/WebKit/Typora"
  "$LIBRARY_DIR/HTTPStorages/abnerworks.Typora"
  "$LIBRARY_DIR/HTTPStorages/abnerworks.Typora.binarycookies"
  "$LIBRARY_DIR/HTTPStorages/io.typora.Typora"
  "$LIBRARY_DIR/HTTPStorages/io.typora.Typora.binarycookies"
  "$LIBRARY_DIR/Cookies/abnerworks.Typora.binarycookies"
  "$LIBRARY_DIR/Cookies/io.typora.Typora.binarycookies"
  "$LIBRARY_DIR/Containers/abnerworks.Typora"
  "$LIBRARY_DIR/Containers/io.typora.Typora"
  "$LIBRARY_DIR/Application Scripts/abnerworks.Typora"
  "$LIBRARY_DIR/Application Scripts/io.typora.Typora"
  "$LIBRARY_DIR/Application Support/com.apple.sharedfilelist/com.apple.LSSharedFileList.ApplicationRecentDocuments/abnerworks.Typora.sfl"
  "$LIBRARY_DIR/Application Support/com.apple.sharedfilelist/com.apple.LSSharedFileList.ApplicationRecentDocuments/abnerworks.Typora.sfl2"
  "$LIBRARY_DIR/Application Support/com.apple.sharedfilelist/com.apple.LSSharedFileList.ApplicationRecentDocuments/abnerworks.Typora.sfl3"
  "$LIBRARY_DIR/Application Support/com.apple.sharedfilelist/com.apple.LSSharedFileList.ApplicationRecentDocuments/io.typora.Typora.sfl"
  "$LIBRARY_DIR/Application Support/com.apple.sharedfilelist/com.apple.LSSharedFileList.ApplicationRecentDocuments/io.typora.Typora.sfl2"
  "$LIBRARY_DIR/Application Support/com.apple.sharedfilelist/com.apple.LSSharedFileList.ApplicationRecentDocuments/io.typora.Typora.sfl3"
)

if [[ "$REMOVE_APP" -eq 1 ]]; then
  targets+=(
    "/Applications/Typora.app"
    "$HOME_DIR/Applications/Typora.app"
  )
fi

existing_targets=()
for target in "${targets[@]}"; do
  if [[ -e "$target" || -L "$target" ]]; then
    existing_targets+=("$target")
  fi
done

while IFS= read -r crash_file; do
  existing_targets+=("$crash_file")
done < <(find "$LIBRARY_DIR/Logs/DiagnosticReports" -maxdepth 1 \( -name 'Typora*.crash' -o -name 'Typora*.ips' -o -name 'Typora*.diag' \) 2>/dev/null || true)

echo "Typora cleanup targets:"
if [[ "${#existing_targets[@]}" -eq 0 ]]; then
  echo "  No known Typora local data was found."
else
  printf '  %s\n' "${existing_targets[@]}"
fi

if [[ "$DRY_RUN" -eq 1 ]]; then
  echo
  echo "Dry run only. Nothing was removed."
  exit 0
fi

if [[ "${#existing_targets[@]}" -eq 0 ]]; then
  exit 0
fi

if pgrep -x Typora >/dev/null 2>&1; then
  echo
  echo "Typora is running. Please quit Typora before continuing."
  if [[ "$YES" -eq 1 ]]; then
    osascript -e 'tell application "Typora" to quit' >/dev/null 2>&1 || true
    sleep 2
  else
    read -r -p "Quit Typora now and continue? [y/N] " quit_answer
    case "$quit_answer" in
      y|Y|yes|YES)
        osascript -e 'tell application "Typora" to quit' >/dev/null 2>&1 || true
        sleep 2
        ;;
      *)
        echo "Canceled."
        exit 1
        ;;
    esac
  fi
fi

if [[ "$YES" -ne 1 ]]; then
  echo
  read -r -p "Remove the Typora data listed above? [y/N] " answer
  case "$answer" in
    y|Y|yes|YES)
      ;;
    *)
      echo "Canceled."
      exit 1
      ;;
  esac
fi

for target in "${existing_targets[@]}"; do
  rm -rf -- "$target"
done

defaults delete abnerworks.Typora >/dev/null 2>&1 || true
defaults delete io.typora.Typora >/dev/null 2>&1 || true
killall cfprefsd >/dev/null 2>&1 || true

echo "Typora local data cleanup complete."
if [[ "$REMOVE_APP" -eq 0 ]]; then
  echo "Run again with --remove-app if you also want to remove Typora.app."
fi
